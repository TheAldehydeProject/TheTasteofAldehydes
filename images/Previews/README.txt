The home page's map: one picture of each page a node leads to, shown in that
node's window (the `image` in REAL_NODES in node-scene.js).

They are taken, not drawn: run `node tools/previews.js` from the repository's
root (after `npm install` once) to take them all again, or name the ones you
want — `node tools/previews.js theories contact`. Each is 960 x 720, JPEG.
